# DESIGN.md — 오토끼의 시간여행

> UI·레이아웃·이미지·카피를 바꿀 때 먼저 읽는 규칙 문서입니다. 사람이든 AI든 여기에 없는 값을 새로 만들지 않습니다.

## 1. 성격 (한 문장)
**"밤의 극장에서 펼쳐지는 동화책 한 장."** 원장님이 믿고 맡길 수 있게 차분하고 또렷하게 쓰고, 동화 같은 설렘은 제목·캐릭터·무대 장면에서만 보여 준다.

- 우리가 아닌 것: ① 보라·파스텔 그라데이션의 "AI 키즈 SaaS" ② 모든 것을 둥근 카드에 넣은 템플릿 ③ 이모지로 때운 아이콘
- 주 독자: 원장님(결정), 선생님(실무). 아이는 사진과 캐릭터 속에 있지, UI의 독자가 아니다.

## 2. 색 (로고에서 추출, 시맨틱 토큰만 사용)
| 토큰 | 값 | 용도 |
|---|---|---|
| `stage` | #14324A | 어두운 무대 배경, 본문 글자 |
| `paper` | #F7F1E8 | 기본 바탕 |
| `paper-deep` | #EFE6D8 | 구역 구분 바탕 |
| `gold` | #D9B48C | 주요 행동(전화 문의) 버튼 배경 |
| `gold-ink` | #7A5C43 | 작은 라벨, 보조 강조 글자 (paper 위 대비 4.5:1 이상) |
| `plum` | #5B1F77 | 메타버스 무빙 씨어터 관련 표시에만 |
| `line` | #D8CBB8 | 구분선 |
| `muted` | #3E5568 | 보조 본문 |
- 캐릭터 라벤더·하늘색은 **캐릭터 이미지 안에만** 존재한다. UI 색으로 쓰지 않는다.
- 그라데이션은 사진 위 가독성 오버레이(stage → 투명)에만 쓴다.

## 3. 글꼴
- 제목: **고운바탕 Bold** (로고의 동화책 세리프와 어울림). H1·H2·공연 제목에만 사용.
- 본문·UI: **Pretendard** 400/600. 굵기는 이 두 가지만.
- 단계: H1 56/1.2 · H2 40/1.25 · H3 24/1.35 · 본문 17/1.75 · 라벨 13(자간 0.12em) — 모바일은 H1 36, H2 28.

## 4. 레이아웃
- 기본 폭 1120px, 본문 단 최대 640px.
- **카드는 "독립적으로 고르는 대상"에만.** 프로그램 목록은 공연 안내지(플레이빌)처럼 번호 + 구분선 목록으로.
- 전폭(full-bleed)은 ① 첫 화면 무대 ② 무빙 씨어터 해부도 ③ 현장 사진에만.
- 모서리: 0 / 8px(버튼·이미지) / 999px(배지만). 그림자는 쓰지 않거나 사진 한 종류만.

## 5. 이미지·캐릭터
- 캐릭터 원본: `public/images/poses/pose-a~j.webp`. 한 화면(섹션)에 캐릭터는 한 번만, 이야기하는 위치에만.
- 로고: `public/brand/otoki-logo.svg`(금색), `otoki-logo-mono.svg`(currentColor), `mmt-logo.svg`, `whoseegg-logo.webp`.
- 현장 사진의 아이 얼굴은 항상 블러. 사진 비율은 3:2 또는 16:9로 통일.
- 존재하지 않는 이미지 파일명을 쓰지 않는다.

## 6. 아이콘
- 한 가족만 사용(선 굵기 1.75, 20/24px). 이모지는 캐릭터 말풍선 같은 "이야기" 안에서만.

## 7. 움직임
- 남길 것: 무빙 씨어터 해부도, 공연 전·당일·후 스크롤 장면, AI 검색 모션그래픽. 첫 화면은 속도(LCP)를 위해 정지 화면으로 둔다.
- 금지: 모든 섹션에 똑같은 페이드업, 모든 카드에 호버 확대·기울기, 떠다니는 장식.
- `prefers-reduced-motion`이면 모든 연출을 끈다.

## 8. 카피
- 원장님 언어로: 혜택 → 근거(숫자·기관) 순서. 근거 없는 숫자·후기 금지.
- 버튼은 다음 행동을 말한다: "공연 일정 전화 문의", "환경교육 공연 보기".
- 같은 문장 구조(“~해요. ~해요.”)를 세 번 연속 쓰지 않는다.

## 9. 알려진 실패 패턴 (발견하면 고친다)
- OTK-CARD-01: 모든 내용을 둥근 카드로 감싸기
- OTK-COLOR-01: 로고에 없는 보라·파스텔 그라데이션 배경
- OTK-ICON-01: 이모지를 기능 아이콘으로 사용
- OTK-MOTION-01: 모든 섹션 동일한 등장 효과
- OTK-CHAR-01: 한 화면에 캐릭터를 장식으로 여러 번 배치

## 10. 완료 기준
- 390px·1440px 화면에서 확인, 키보드 초점이 항상 보임
- 글자 대비 4.5:1(큰 글자 3:1) 이상
- LCP 2.5초 이하, CLS 0.1 이하 (모바일 Lighthouse)
- 새 색·모서리·그림자 값을 추가하지 않음
