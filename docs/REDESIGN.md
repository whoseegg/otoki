## 2. 방향 — "밤의 극장에서 펼쳐지는 동화책"
- 색: 로고에서 추출한 **무대 남색(#14324A) + 시계 금색(#D9B48C) + 종이색(#F7F1E8)**. 보라는 무빙 씨어터 로고 표시에만.
- 글꼴: 제목 **고운바탕**(로고의 동화책 세리프와 어울림) + 본문 **Pretendard**.
- 구성: 카드 대신 **공연 안내지(플레이빌)** 형식의 번호 목록, 전폭 무대 장면, 큰 현장 사진.
- 캐릭터: 원본 포즈 10종 고해상도 교체, 섹션당 한 번만.
- 무드보드: 대화에 첨부한 `moodboard.png`

## 4. 검증 방법 (트래픽이 적은 사이트에 맞춤)
- **블라인드 비교**: 현재안(A)과 개선안(B) 캡처를 어느 쪽이 새것인지 말하지 않고 원장님·선생님 6~8명에게 보여 주고 질문
  - "어느 쪽 공연에 더 믿고 문의하시겠어요?"
  - "이 화면에서 가장 먼저 할 행동은?" (전화 문의를 고르는지)
  - "다른 공연 업체와 구분되는 정도" 1~7점
- **운영 지표**: 전화 버튼 클릭 수(GA4·네이버 애널리틱스 이벤트), 네이버 플레이스 안심번호 통화 수. A/B로 통계적 유의성을 보기에는 트래픽이 적으므로 오픈 전후 4주 추이로 본다.
- **기준선**: 모바일 Lighthouse 성능·접근성 점수, LCP ≤ 2.5초, CLS ≤ 0.1.
