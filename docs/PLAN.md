# 오토끼의 시간여행 홈페이지 — 기획서 v1

> 오토끼의 시간여행은 ㈜후즈에그가 개발하고 주관하는 공연입니다.
> 근거 자료: 오토끼의 시간여행 소개서, MMT v2.0 설치·앱 매뉴얼, 지원사업 성과 자료.
> 기존 피그마(폐기안)는 참고만 하고, 구조와 카피는 새로 작성했습니다.

## 1. 목표
1. **문의 전환**: 원장님·선생님이 어느 페이지에서든 3클릭 안에 문의할 수 있게 한다.
2. **검색 노출(SEO)**: 네이버·구글·다음에서 "유치원 공연", "어린이집 방문 공연", "유아 환경교육", "장애인식개선교육", "메타버스 체험", "AI 체험", "방문 행사" 같은 키워드로 노출되게 한다.
3. **AI 답변 노출(GEO)**: ChatGPT, Claude, Perplexity, 네이버 AI 브리핑 같은 AI 검색이 오토끼를 정확히 이해하고 인용하게 한다.

## 2. 카피 전략

### 2-1. 타깃별 핵심 메시지
| 타깃 | 속마음(소개서 FAQ에서 그대로 가져옴) | 오토끼의 답 |
|---|---|---|
| 원장님 (결정권자) | "기존 공연은 이제 너무 식상해요" | 인형극도 영상도 아닌, 처음 보는 공연 (홀로그램 + 오토마타 + 배우) |
| 원장님 (리스크) | "아이들이 좋아할지 걱정이에요" | 누적 1,800회 이상, 공공기관·센터 공연 실적, 언론 보도 |
| 선생님 (실무) | "선생님들이 힘들지 않았으면 좋겠어요" | 설치·진행·철수는 공연팀이, 사전·사후 자료 제공 |
| 원장님 (교육 계획) | 행사와 교육을 따로 챙기는 부담 | 환경·장애인식개선 같은 교육 주제를 공연 한 번에 |
| 학부모 (간접) | 우리 아이가 무엇을 배웠는지 | 가정연계활동지, 하원길 대화, 포토타임 |

### 2-2. 메인 카피
- **헤드라인**: 문을 열면, 시간여행이 시작돼요
- **서브**: 3D 홀로그램, 움직이는 오토마타 무대, 그리고 배우 오토끼. 강당 대관도 버스도 없이, 아이들이 처음 만나는 공연이 우리 원으로 찾아갑니다.
- **고민 공감**: 좋은 공연은 늘 필요한데, 고르기는 늘 어렵죠
- **차별점**: 극장이 통째로, 우리 원에 찾아와요
- **교육 연속성**: 공연은 하루, 시간여행은 계속돼요 (D-7 → D-DAY → AFTER)
- **AI 섹션**: 요즘 선생님들은 AI에게 먼저 물어보세요 + "AI가 선택한 공연" 배지
- **마지막 CTA**: "오토끼 또 언제 와요?" 그 질문을 우리 원에서도 들어 보세요

### 2-3. 원칙
- 원장님 언어로 쓴다: "SDGs", "PBL"은 근거로만 쓰고 혜택("행사와 교육을 한 번에")을 먼저 말한다.
- 숫자와 기관명으로 신뢰를 준다: 실제 자료에 있는 것만 쓰고, 임의의 숫자나 후기는 만들지 않는다.
- 프로그램 페이지마다 원장님 / 선생님 / 학부모 세 관점의 문장을 둔다.

## 4. AI 검색 모션그래픽
- 코드로 그린 모션그래픽(`components/AiSearchVideo.tsx`)이라 선명하고 가볍습니다. 텍스트도 검색엔진이 읽을 수 있습니다.
- 질문 4종(방문 공연 / 장애인식개선 / 환경교육 / 메타버스)이 반복될 때마다 바뀝니다.
- 같은 화면을 MP4로 녹화했습니다: `public/media/otoki-ai-search-16x9.mp4`(블로그·유튜브용), `otoki-ai-search-9x16.mp4`(릴스·쇼츠용). 다시 만들려면 `npm run build && npm start`를 실행한 뒤 다른 터미널에서 `npm run video`를 실행합니다.
- ⚠️ **표시·광고 주의**: 화면 아래에 "이해를 돕기 위해 연출한 화면" 안내 문구를 넣었습니다. 실제 AI 답변에서 오토끼가 추천되는지 정기적으로 확인하고, 확인되면 실제 화면 캡처로 바꾸는 것을 권장합니다. 특정 AI 서비스(ChatGPT, 네이버 등)의 로고나 화면을 흉내 내지 않았습니다.

## 6. 오픈 후 해야 할 일 (사이트 밖 작업)
1. **네이버 서치어드바이저**: 사이트 등록, 소유 확인(`NEXT_PUBLIC_NAVER_SITE_VERIFICATION`), 사이트맵 제출, 수집 요청
2. **구글 서치콘솔**: 등록(`NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`), 사이트맵 제출
3. **다음 검색 등록**
4. **네이버 스마트플레이스** 등록 (업종: 공연·교육 서비스)
5. **네이버 블로그**: 월 2~4회 공연 후기를 발행하고 홈페이지 링크를 단다 (9:16 영상을 클립과 릴스에 활용)
6. **언론 보도 원문 링크** 수집 → `lib/press.ts`의 `url`에 입력 (외부 출처는 AI 인용 신뢰도를 높입니다)
7. 분기마다 AI 검색(ChatGPT, Perplexity, 네이버 AI 브리핑 등)에서 핵심 질문을 직접 검색해 노출 여부를 기록
